Frequently Asked Questions

Click any question to expand the answer and test accordion tracking.

How are click coordinates normalized across different screen sizes? +
The tracker captures both absolute document coordinates (x, y) and current viewport width/height. The backend calculates normalized coordinates (x / viewport.width, y / viewport.height) so the React heatmap can scale accurately regardless of screen size!
Does the tracking SDK slow down page rendering? +
Not at all! The SDK attaches a single top-level event listener with event delegation and uses non-blocking asynchronous fetch(..., { keepalive: true }) and sendBeacon fallbacks.
How does session persistence work across browser tabs? +
Sessions are managed via sessionStorage. Each browser tab receives a persistent UUID. Navigating between pages in the same tab preserves the journey, while opening a fresh tab begins a separate session!

🔒 Built-in Privacy Rules

How the Vanilla JS Tracker SDK safeguards user data:

  • Password Field Masking: Any input[type="password"] click or value is strictly ignored.
  • PII Sanitization: Form values with sensitive tokens are never sent over the wire.
  • Configurable Blacklists: Elements marked with data-analytics-ignore are skipped completely.
  • Cookie-Free Architecture: Relies on tab-scoped sessionStorage rather than third-party tracking cookies.
